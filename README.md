# cloth-measure

透過手機拍照，自動量測平鋪衣物的 **衣長 / 胸寬 / 下擺 / 肩寬**。

單檔前端，無需建置流程。全部運算在瀏覽器端完成，照片不會離開裝置。

## 原理

1. **ArUco 校正** — 板面四角貼 4 張 50 mm ArUco 標記（`DICT_4X4_50`, ID 0–3）。
   偵測後先用四個標記中心解粗略 homography，再把 16 個角點投影到世界座標做最近鄰配對，
   最後以最小二乘解出精確 homography。這樣完全不依賴位元旋轉判定，避免標記被判成 90°/180° 的失敗模式。
2. **Otsu 分割** — 在四個標記圍出的矩形內做全域二值化，取最大連通元件並填滿外輪廓。
3. **對稱軸轉正** — 以 0.25° 步進搜尋鏡像 IoU 最大的角度，把衣物轉正。
   IoU 同時作為品質閘門（< 0.75 代表袖子沒攤平）。
4. **特徵點量測** — 由寬度剖面取衣長、腋下最窄處（胸寬）、下擺；肩寬給初值後由人工確認。

## 使用

1. 列印 `aruco_A4_50mm.pdf`（**務必選「實際大小 / 100%」**），
   剪下後貼在板面四角，量測並填入 `m` / `W` / `H` 三個常數。
2. 開啟 `index.html`，選擇照片，按「開始分析」。
3. 拖曳圖上的圓點可修正端點，數字即時更新。

## 拍攝條件

- 背景需與衣物有明顯明暗對比（例如淺灰板配深色衣）
- 衣物平鋪、袖子左右對稱攤開
- 四張 ArUco 完整入鏡且未被遮擋
- 光線均勻，避免硬光在衣物邊緣造成投影

## 實測精度

同一件 T 恤、四種不同拍攝角度與擺放方式：

| | 衣長 | 胸寬 | 下擺 | 肩寬 |
|---|---|---|---|---|
| 變異 | ±0.25 cm | ±0.9 cm | ±0.7 cm | ±2.1 cm |

Reprojection error 1.15–1.50 px、對稱 IoU 0.966–0.979、單張處理約 3.4 秒。

肩寬倚賴曲率極值，在落肩與連袖款式上不可靠，因此介面上標記為需人工確認。
