# cloth-measure

透過手機拍照，自動量測平鋪衣物的尺寸。會自動判斷是上衣還是下著，套用對應的量測項目：

| 類型 | 量測項目 |
|---|---|
| 上衣 | 衣長 / 胸寬（腋下）/ 肩寬 / 下擺 |
| 下著 | 褲長 / 腰寬 / 股上 / 褲口 |

分類純粹看遮罩形狀，不呼叫任何模型。判錯時（開襟外套最容易被當成下著）可在結果卡上手動切換。

單檔前端，無需建置流程。全部運算在瀏覽器端完成，照片不會離開裝置。

## 支援的板子

| 板子 | 標記 | 偵測條件 |
|---|---|---|
| 綠板 v2（1000×1300 mm 印刷版） | 20 個 60 mm `DICT_5X5_100`，座標內建 | 邊框任意 ≥4 個即可校正，被遮擋沒關係 |
| 四角標記板（自貼 4×4） | 4 個 `DICT_4X4_50`，幾何由頁面常數輸入 | 4 個全部可見 |

兩種同時支援、自動判別（v2 優先）。綠板底色 #00B140 對深淺色衣物皆可分割，
僅與板同色系的亮綠色衣物除外——那些請改用灰板拍。

## 原理

1. **ArUco 校正** — 板面四角貼 4 張 50 mm ArUco 標記（`DICT_4X4_50`, ID 0–3）。
   偵測後先用四個標記中心解粗略 homography，再把 16 個角點投影到世界座標做最近鄰配對，
   最後以最小二乘解出精確 homography。這樣完全不依賴位元旋轉判定，避免標記被判成 90°/180° 的失敗模式。
2. **背景色差分割** — 在四個標記圍出的矩形內，從邊框取樣建立背景的 Lab 色彩統計模型
   （平均與共變異數），對每個像素計算馬氏距離後再二值化。這樣同時利用色度與亮度，
   淺色衣物放在淺色背景上（例如米色條紋 Polo 配灰板）也切得出來——單看亮度的 Otsu
   在這種情況會把淺色條紋當成背景丟掉。Otsu 保留為備援，面積佔比不合理時自動換用。
3. **分支選擇** — 大核心閉運算能把條紋衣物碎裂的遮罩接回來，卻也會填掉短褲的褲襠。
   因此兩種遮罩都算出來再比較：閉運算對下著只多補一小塊褲襠三角形（保留率 0.97–1.00），
   對碎裂的條紋上衣則救回大半個身體（保留率 0.44–0.56）。門檻 0.75 落在中間的空白帶。
   接著量測輪廓的周長平方 / 面積：邊界一直在衣物與板面之間跳動時這個值會偏高，
   超過 30 就以現有遮罩為種子跑 GrabCut 精修，用色彩模型加平滑先驗重畫邊界。
4. **合理性閘門** — 遮罩面積必須佔板面 8–75%，否則直接報錯並提示更換背景，
   不輸出任何數字。
5. **對稱軸轉正** — 以 0.25° 步進搜尋鏡像 IoU 最大的角度，把衣物轉正。
   IoU 同時作為品質閘門（< 0.75 代表袖子沒攤平）。
6. **類型判定** — 上衣只有淺淺的領口缺口，下著則被褲襠從一端劈開很長一段。
   量測缺口從兩端各自延伸的深度，即可同時判斷「是上衣還是下著」與「哪一端朝上」。
   實測上衣 0.02–0.05、短褲 0.23–0.30，分界設在 0.18。介面上可手動覆寫。
7. **特徵點量測** — 衣長取遮罩高度；胸寬取袖子下方最窄處；下擺取底部 20% 列寬度的
   90 百分位（可同時處理平直下襬與 Polo 的彎弧下襬）；肩寬由胸寬推估初值後人工確認。
   胸寬只在袖寬最大列往下 35% 高度內尋找最窄處：腋下必定緊接在袖子下方，
   搜尋到下襬會讓方正版型的身體勝出，把線拉得太低。
   下著取腰頭中段的中位數為腰寬（跳過凸出的褲耳）；褲襠定義為「缺口一路延伸到下襬的
   最高那一列」，股上即腰頭上緣到褲襠的距離；褲口取單邊褲管寬度，但褲管張開時下襬是
   斜的，所以褲口做成可自由拖曳的斜線段，並標記為需人工確認。

## 使用

1. 列印 `aruco_A4_50mm.pdf`（**務必選「實際大小 / 100%」**），
   剪下後貼在板面四角，量測並填入 `m` / `W` / `H` 三個常數。
2. 開啟 `index.html`，選擇照片，按「開始分析」。
3. 拖曳圖上的圓點可修正端點，四項尺寸（含衣長）都可調整，數字即時更新。
   拖曳時角落會出現放大鏡，避免指尖遮住正在對齊的點。

## 拍攝條件

- 背景需與衣物有明顯色彩差異（深色衣配淺色板最穩；淺色衣建議改用深色板）
- 衣物平鋪、袖子左右對稱攤開
- 四張 ArUco 完整入鏡且未被遮擋
- 光線均勻，避免硬光在衣物邊緣造成投影

## 實測精度

同一件 T 恤、四種不同拍攝角度與擺放方式：

| | 衣長 | 胸寬 | 肩寬 | 下擺 |
|---|---|---|---|---|
| 3970 | 63.8 | 48.1 | 45.7 | 52.5 |
| 3971 | 64.0 | 48.0 | 45.6 | 52.5 |
| 3972 | 64.0 | 48.8 | 46.3 | 52.6 |
| 3975 | 63.5 | 49.6 | 47.2 | 52.4 |
| **變異** | **±0.25** | ±0.8 | ±0.8 | **±0.1** |

Polo（淺色條紋，與板面對比極低）：衣長 75.0、胸寬 44.0、肩寬 41.8、下擺 46.2 cm
寬領背心（藍白條紋，上下顛倒拍攝）：衣長 55.0、胸寬 43.0、肩寬 40.9、下擺 43.5 cm
　　缺口深度 0.158，離門檻 0.18 只差 0.022 — 更深的 V 領或大挖背可能被誤判，用手動切換修正。

短褲 A：褲長 51.0、腰寬 39.0、股上 36.3、褲口 16.4 cm
短褲 B：褲長 45.5、腰寬 39.1、股上 35.2、褲口 13.9 cm

股上與褲口倚賴褲管的擺放方式：褲管併攏時輪廓的分岔點會低於真正的褲襠，股上會偏大。
兩者皆標記為需人工確認。

Reprojection error 1.15–1.50 px、對稱 IoU 0.967–0.984、單張處理約 5 秒。

肩寬無法可靠自動偵測：平鋪 T 恤的肩線與袖子上緣幾乎共線，輪廓上沒有轉折點可尋。
初值改由胸寬推估（約 0.95 倍），介面上標記為需人工確認，拖曳即可修正。

## 診斷資訊

頁面標題旁顯示建置時間戳記，任何時候都能確認手機與桌機跑的是不是同一份。

結果下方的「診斷資訊」列出裝置、解碼尺寸、Otsu 閾值、分支保留率、對稱 IoU、缺口深度等中間值，
可一鍵複製。不同裝置結果不一致時，比對這些數字即可定位。
