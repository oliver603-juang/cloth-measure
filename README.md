# cloth-measure

透過手機拍照，自動量測平鋪衣物的尺寸。會自動判斷是上衣還是下著，套用對應的量測項目：

| 類型 | 量測項目 |
|---|---|
| 上衣 | 衣長 / 胸寬（腋下）/ 肩寬 / 下擺 |
| 下著 | 褲長 / 腰寬 / 臀寬 / 褲口 |

單檔前端，無需建置流程。全部運算在瀏覽器端完成，照片不會離開裝置。

## 原理

1. **ArUco 校正** — 板面四角貼 4 張 50 mm ArUco 標記（`DICT_4X4_50`, ID 0–3）。
   偵測後先用四個標記中心解粗略 homography，再把 16 個角點投影到世界座標做最近鄰配對，
   最後以最小二乘解出精確 homography。這樣完全不依賴位元旋轉判定，避免標記被判成 90°/180° 的失敗模式。
2. **背景色差分割** — 在四個標記圍出的矩形內，從邊框取樣建立背景的 Lab 色彩統計模型
   （平均與共變異數），對每個像素計算馬氏距離後再二值化。這樣同時利用色度與亮度，
   淺色衣物放在淺色背景上（例如米色條紋 Polo 配灰板）也切得出來——單看亮度的 Otsu
   在這種情況會把淺色條紋當成背景丟掉。Otsu 保留為備援，面積佔比不合理時自動換用。
3. **合理性閘門** — 遮罩面積必須佔板面 8–75%，否則直接報錯並提示更換背景，
   不輸出任何數字。
4. **對稱軸轉正** — 以 0.25° 步進搜尋鏡像 IoU 最大的角度，把衣物轉正。
   IoU 同時作為品質閘門（< 0.75 代表袖子沒攤平）。
5. **類型判定** — 上衣只有淺淺的領口缺口，下著則被褲襠從一端劈開很長一段。
   量測缺口從兩端各自延伸的深度，即可同時判斷「是上衣還是下著」與「哪一端朝上」。
   實測上衣 0.02–0.05、短褲 0.30，分界設在 0.18。
6. **特徵點量測** — 衣長取遮罩高度；胸寬取袖子下方最窄處；下擺取底部 20% 列寬度的
   90 百分位（可同時處理平直下襬與 Polo 的彎弧下襬）；肩寬由胸寬推估初值後人工確認。
   下著取腰頭中段的中位數為腰寬（跳過凸出的褲耳）、褲襠以上的最大跨距為臀寬、
   褲口取單邊褲管寬度。

## 使用

1. 列印 `aruco_A4_50mm.pdf`（**務必選「實際大小 / 100%」**），
   剪下後貼在板面四角，量測並填入 `m` / `W` / `H` 三個常數。
2. 開啟 `index.html`，選擇照片，按「開始分析」。
3. 拖曳圖上的圓點可修正端點，四項尺寸（含衣長）都可調整，數字即時更新。
   拖曳時角落會出現放大鏡，避免指尖遮住正在對齊的點。

## 拍攝條件

- 背景需與衣物有明顯色彩差異（深色衣配淺色板最穩；淺色衣建議改用深色板）
- 衣物平鋪、袖子左右對稱攤開
- 四張 ArUco 完整入鏡且未被遮擋
- 光線均勻，避免硬光在衣物邊緣造成投影

## 實測精度

同一件 T 恤、四種不同拍攝角度與擺放方式：

| | 衣長 | 胸寬 | 肩寬 | 下擺 |
|---|---|---|---|---|
| 3970 | 63.8 | 48.1 | 45.7 | 52.5 |
| 3971 | 64.0 | 48.0 | 45.6 | 52.5 |
| 3972 | 64.0 | 48.8 | 46.3 | 52.6 |
| 3975 | 63.5 | 49.6 | 47.2 | 52.4 |
| **變異** | **±0.25** | ±0.8 | ±0.8 | **±0.1** |

Polo（淺色條紋，與板面對比極低）：衣長 75.0、胸寬 44.0、肩寬 41.8、下擺 46.2 cm
短褲：褲長 51.0、腰寬 39.0、臀寬 47.8、褲口 18.2 cm

Reprojection error 1.15–1.50 px、對稱 IoU 0.967–0.984、單張處理約 5 秒。

肩寬無法可靠自動偵測：平鋪 T 恤的肩線與袖子上緣幾乎共線，輪廓上沒有轉折點可尋。
初值改由胸寬推估（約 0.95 倍），介面上標記為需人工確認，拖曳即可修正。
